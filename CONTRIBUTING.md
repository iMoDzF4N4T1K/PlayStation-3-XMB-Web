# Contributing

Thanks for your interest in contributing to **PlayStation-3-XMB-Web (HybrideLabs Web Edition)**.

## Issues / Bug reports

When opening an issue, please include:
- Browser + version
- OS
- Steps to reproduce
- Screenshot/video when relevant
- Console errors (F12 → Console)

## Local development

> ES modules require HTTP. Do **not** run via `file://`.

### Install
```bash
npm install
```

### Run
```bash
npm run start
```

Open `http://localhost:8000`

## Pull requests

Guidelines:
- Keep PRs focused (one topic per PR)
- Avoid huge formatting-only diffs
- For visual/physics changes, add before/after screenshots if possible
- If you touch licensing/credits, keep `THIRD_PARTY_NOTICES.md` up to date
